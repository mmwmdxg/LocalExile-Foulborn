# LocalExile-Foulborn｜中文说明

基于 [LocalExile](https://github.com/LocalExile/LocalExile) 的 Path of Exile 1 **3.29.3b 本地服务端派生项目**，重点补充穢生物品、制作通货及首饰品质计算。不是官方服务器，也不是完整游戏模拟器。

**首次安装请看 [中文安装与使用指南](SETUP.md)**；已有环境可使用 [繁中启动入口](Start-LocalExile-TW.cmd)。

## 运行条件

- Windows 10/11 x64、PowerShell 5.1+、.NET 10 SDK。
- Node.js 24 与 Oodle 解压工具依赖，安装方法见指南。
- 自行合法持有的 **3.29.3b 独立客户端**。不支持用当前最新版或 Steam/Epic 版替代。
- 仓库不提供游戏客户端、提取的游戏数据、账号或密钥。

## 本分支功能与限制

| 功能 | 用法 | 当前边界 |
|---|---|---|
| 穢生（Foulborn）传奇 | `/item foulborn <英文传奇名>` | 已有映射；目前取首个候选并替换末尾显式词缀，不代表所有传奇的正确替换或特殊机制均完成 |
| 穢生增幅石／富豪石／崇高石 | 游戏内右键通货使用 | 复用对应普通通货的本地处理规则 |
| 首饰催化剂 | 右键催化剂，再点击项链、戒指或腰带 | 按类型、词缀标签及可缩放标记计算实际属性；自动测试通过，实机属性对照仍待验证 |
| 品质调试指令 | `/item_quality <品质> [类型行]`、`/item_mods` | 对鼠标上拿着的物品操作；不是批量背包修改 |
| 裁缝宝珠 | 对胸甲使用 | 已有附魔与插槽处理；重铸概率等属于本地实现，不能视为官方规则完全复刻 |
| 机会石 | 对普通物品使用 | 本地传奇尝试，不是官方普通／魔法／稀有／传奇完整概率分布 |
| 正义之火 | 正火玩法相关代码 | 仍有公式、支持及动态范围方面的待完善项，不宣称所有搭配正确 |

完整玩法状态见 [功能状态索引](Agents/Status.md)。能生成或显示物品，不等于其全部玩法机制已经实现。

## 常用示例

```text
/item Onyx Amulet
/item Intrinsic Catalyst 10
/item foulborn Mageblood
```

拿起测试首饰后可使用：

```text
/item_quality 20 6
/item_mods
```

类型 `6` 为属性品质。原始 `+37 力量` 在匹配条件下以 20% 品质计入 `44`，保存的原始词缀仍为 `37`，避免重复放大。请先用测试物品验证，不要直接修改重要装备。

## 安全与更新

- 源码环境只通过 [标准启动脚本](scripts/dev/live.ps1) 或调用它的繁中入口启动，避免官方启动器更新客户端。
- 更新前备份本地存档、密钥及客户端副本；不要把账号、密钥或游戏数据上传 GitHub。
- 当前默认分支为 `main`。部分上游发布脚本及启动器更新提示仍指向原项目；不要据此用上游压缩包覆盖本派生版本。
